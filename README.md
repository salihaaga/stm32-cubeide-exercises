# STM32CubeIDE Eğitim Projeleri

Bu depoda STM32 ile yaptığım temel çevre birimi uygulamaları yer almaktadır.

## Proje İçeriği
* **01_dahili_saat_konfigurasyonu:** Dahili sistem saat ayarları.
* **02_harici_saat_konfigurasyonu:** Harici osilatör (HSE) saat yapılandırması.
* **03_GPIO_cikis_uygulamasi:** LED kontrolü ve dijital çıkış işlemleri.
* **04_GPIO_giris_uygulamasi:** Buton okuma ve dijital giriş uygulaması.
* **05_buton_durum_ile_led_kontrolu:** Buton durumuna göre LED kontrolü.
* **06_harici_kesme:** EXTI (External Interrupt) kullanımı.
* **07_ADC_konfigurasyonu:** Analog-Dijital Dönüştürücü (ADC) kullanımı.

## Kullanılan Araçlar
* **Geliştirme Kartı:** STM32F411VET6
* **Geliştirme Ortamı:** STM32CubeIDE, STM32CubeMX, STM32CubeProgrammer, STM32CubeMonitor
* **Dil / Kütüphane:** C Dili (STM32Cube HAL)
